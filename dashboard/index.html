Data-quality checks from the latest pipeline run

Checks are code, not vibes: they live in the standalone honest_checks package and every run emits a JSON + Markdown report. A failed check stays visible here instead of being quietly fixed in a spreadsheet. That is the point of the platform: a credible-looking wrong number is worse than no number.
